Apresentação

PITCH-FEIRA.md tem a ideia de como apresentar o projeto na ExpoCEEP: o que é o produto, em que ordem contar, o pedaço de fala de cada um e as perguntas que os avaliadores costumam fazer.

Onde a gente conversa

💬 Discord da equipe: https://discord.gg/S3HyaNr3X

É lá que sai o briefing de segunda, o horário de dúvida e o "peguei essa issue". Dúvida no canal, não no direct: a resposta serve pros outros também.

O porquê de cada decisão fica no Pull Request, e PR mergeado continua aberto pra leitura pra sempre, com os comentários de linha do lado do código que mudou. Pra entender por que alguma coisa está do jeito que está, procura o PR que mexeu nela em Pull requests → Closed.
